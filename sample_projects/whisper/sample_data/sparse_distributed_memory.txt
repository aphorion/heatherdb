Elastic Associative Memory (SDM) is a mathematical model of human long-term memory introduced by Pentti Kanerva in 1988. It is designed to handle high-dimensional binary vectors and provides a mechanism for storing and retrieving patterns in a way that mimics the associative nature of biological memory. Unlike traditional databases that store records at specific addresses, SDM distributes each memory across many storage locations and reconstructs memories through a convergence process.

The core idea behind SDM is that memory is content-addressable rather than location-addressable. When you want to recall something, you don't need an exact key — you provide a cue, and the memory system reconstructs the stored pattern that best matches your cue. This means that even noisy, partial, or degraded cues can successfully retrieve the original memory, much like how humans can recognize a friend's face even in poor lighting or from an unusual angle.

SDM consists of a large number of hard locations, each with an address vector and a set of counters. When a pattern is written to memory, it is distributed across all locations whose addresses are sufficiently similar to the pattern. The counters at each activated location are incremented or decremented based on the pattern's components. This distributed storage means that a single memory is spread across many locations, and a single location participates in storing many different memories.

Reading from SDM involves activating the locations nearest to the query vector and summing their counter values. The resulting sum vector is then thresholded to produce a binary output. This output represents the memory's best reconstruction of what was stored at or near the query address. The reconstruction process naturally handles noise because the distributed storage creates a voting mechanism — the correct components of a pattern reinforce each other across many locations, while noise components cancel out.

One of the most remarkable properties of SDM is its ability to handle the superposition of multiple memories. When several patterns are stored in overlapping sets of locations, the memories interfere with each other in controlled ways. Frequently stored patterns create stronger signals that reconstruct more reliably, while rarely stored patterns produce weaker signals that may be overshadowed. This mirrors how human memory works — frequently rehearsed information is easier to recall, while rarely accessed memories fade over time.

The capacity of SDM depends on the relationship between the number of hard locations, the dimensionality of the vectors, and the number of stored patterns. As more patterns are stored, the interference between memories increases, leading to graceful degradation rather than catastrophic failure. The memory doesn't suddenly break when it reaches capacity — instead, the quality of reconstructions gradually decreases, with the most frequently reinforced patterns persisting the longest.

SDM also exhibits basin of attraction behavior, similar to Hopfield networks. Each stored memory creates an attractor in the memory space — a region where nearby queries are pulled toward the stored pattern during reconstruction. These basins of attraction mean that the memory is robust to perturbations: a query that is close to a stored pattern will converge to that pattern, effectively correcting errors in the input.

The biological plausibility of SDM has been a subject of ongoing research. The model's properties — distributed storage, content-addressable retrieval, graceful degradation, and basins of attraction — all have parallels in neuroscience. The cerebellum, in particular, has been proposed as a biological implementation of SDM, with its vast number of granule cells serving as hard locations and its Purkinje cells performing the summation and thresholding operations.

Recent advances have extended the original SDM model in several ways. Adaptive SDM introduces self-organizing locations that migrate toward frequently accessed regions of the memory space, improving storage efficiency. Energy-based retrieval using Hopfield dynamics provides more accurate reconstructions by iteratively refining the read output. These extensions make SDM more practical for real-world applications while preserving its core associative properties.

Applications of SDM span multiple domains. In natural language processing, SDM can serve as an associative memory for text embeddings, enabling recall that is fundamentally different from vector similarity search. In robotics, SDM can store and recall sensorimotor patterns, allowing robots to generalize from past experiences. In anomaly detection, the reconstruction error of SDM provides a natural measure of how unusual a new observation is relative to previously seen patterns. The technology represents a bridge between neuroscience-inspired computing and practical engineering.
