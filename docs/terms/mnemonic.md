# Mnemonic

A stored rule rather than a stored answer — the thing that produces cases you
have never seen.

## Like you're twelve

There is a difference between remembering that 7 × 8 is 56 and knowing how to
multiply. The first is one fact, useless for 7 × 9. The second is a rule that
makes 56, and 63, and a product nobody has ever asked you for.

Both live in memory. Only one of them travels.

## Precisely

A worked example stored verbatim is recalled only by situations that resemble
it. A mnemonic is the relationship itself, held as a bound vector: given the
same relation observed in several different contexts, the shared component is
recoverable, and applying it to a new context derives the case that was never
stored.

Concretely, if each instance is `bind(situation, response)`, then the relation
common to all of them survives [bundling](bundle.md) while the situation-specific
parts interfere away. [Unbinding](unbind.md) that bundle with a fresh situation
yields the response appropriate to it.

Two bounds. Capacity is finite, so a single vector holds a limited number of
instances before interference dominates — the escape is more vectors, not a
bigger one. And contradiction is not resolved silently: two instances that
disagree about the same situation weaken each other rather than one winning, so
disagreement shows up as low [fidelity](fidelity.md) and is detectable before it
is acted on.
